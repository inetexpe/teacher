# Кабінет викладача

Мініапка для викладача іноземної мови: учні, розклад, плани уроків, матеріали й завдання,
плюс кабінет учня за посиланням-запрошенням. Працює як Telegram Mini App і в браузері.

- Апка: `index.html` (один файл, без збірки). Сайт: https://inetexpe.github.io/teacher/
- Синхронізація через Supabase: див. [`supabase/README.md`](supabase/README.md)
